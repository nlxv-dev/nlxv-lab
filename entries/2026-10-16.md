## Project 02 — Neo Finance

### Statistics v1

The main Neo Finance work focused on turning the mock Statistics tab into a functional financial analytics experience.

#### Architecture & UX

- Researched financial analytics UX and modern fintech spending patterns.
- Established a structure based around periods, summaries, trends, categories and transaction details. Similar patterns are used in current financial products such as Revolut.
- Defined a clear separation of responsibilities:
  - **Home** — current financial state;
  - **Statistics** — financial analysis.

#### Implemented

- Replaced the mock Statistics screen with a functional analytics view.
- Added:
  - All / Income / Expenses;
  - month navigation;
  - total summary;
  - spending/income trend chart;
  - income and expense totals;
  - category breakdown;
  - category percentages and amounts.
- Categories are now based on real transaction data.

#### Inline Category Details

The original category detail panel was redesigned after being found disconnected from the category that triggered it.

The new interaction:

- expands directly beneath the selected category;
- smoothly pushes the remaining categories downward;
- keeps only one category expanded at a time;
- collapses the previous category when another is selected;
- collapses when the active category is tapped again;
- removes the redundant "← All" control;
- uses smooth expand/collapse motion.

#### Home Screen

- Removed the Income / Expenses cards from the main balance section.
- Moved their analytical role into Statistics.
- Home now follows a clearer hierarchy: **Balance → Monthly change → Budget → Recent transactions.**

This reduces duplicated information and keeps the Home screen focused on the user's most important current financial state.

#### Data Foundation

- Corrected monthly calculations.
- Budget spending is now calculated against the current month.
- Added the foundation for full transaction dates using `YYYY-MM-DD`.
- Prepared the data model for future:
  - period comparisons;
  - JSON backup;
  - CSV export/import;
  - cross-device data migration.

---

## End Result

- **NLXV Labs:** evolved from a visual prototype into a modular, lightweight platform with its own Markdown-based development log.
- **Neo Finance:** evolved from mock navigation into a functional Statistics foundation, while Home became cleaner and category analysis gained contextual inline interaction.

## Проект 02 — Neo Finance

### Statistics v1

Основная работа над Neo Finance была сосредоточена на превращении мокового раздела «Статистика» в полноценный аналитический экран.

#### Архитектура и UX

- Проведён анализ UX финансовых приложений и подходов к отображению spending analytics.
- За основу взяты распространённые fintech-паттерны: период, итоговые показатели, динамика, категории и детализация. Подобная структура используется и в современных финансовых продуктах, включая Revolut.
- Определено разделение ответственности:
  - **Главная** — текущее финансовое состояние;
  - **Статистика** — анализ финансового поведения.

#### Реализовано

- Моковая вкладка «Статистика» заменена рабочим экраном.
- Добавлены:
  - Все / Доходы / Расходы;
  - переключение месяцев;
  - общий итог;
  - график динамики;
  - доходы;
  - расходы;
  - распределение расходов по категориям;
  - проценты и суммы категорий.
- Категории работают с реальными транзакциями, а не с демонстрационными данными.

#### Inline-детализация категорий

Отдельная детализация категории была признана неудобной: информация появлялась далеко под всем списком категорий.

Механика полностью переработана:

- категория раскрывается непосредственно на своём месте;
- детализация появляется из-под выбранной категории;
- остальные категории плавно сдвигаются вниз;
- одновременно открыта только одна категория;
- выбор другой категории плавно закрывает предыдущую и раскрывает новую;
- повторный тап закрывает текущую категорию;
- лишняя кнопка «← Все» удалена;
- добавлена плавная анимация раскрытия/сворачивания.

#### Главная

- Убраны карточки «Доход» / «Расход» из-под основного баланса.
- Их аналитическая функция перенесена в Statistics.
- Главная теперь строится вокруг: **Баланс → изменение за месяц → бюджет → последние транзакции.**

Это уменьшает дублирование информации и оставляет Home сфокусированным на наиболее важных текущих показателях.

#### Фундамент данных

- Исправлен расчёт месячных показателей.
- Расходы бюджета теперь корректно относятся к текущему месяцу.
- Добавлена основа для полноценной даты транзакции в формате `YYYY-MM-DD`.
- Это создаёт фундамент для:
  - корректной статистики;
  - сравнения периодов;
  - будущего JSON backup;
  - CSV export/import;
  - переноса данных между устройствами.
